Query Translation

пять способов переформулировать запрос до поиска — конспект по мотивам RAG From Scratch

выявленный пробел ученика

Multi-Query

Пример: «чем отличается Present Perfect от Past Simple» → 3 формулировки → результаты объединяются без повторов.

RAG-Fusion

Пример: документ на 2-м месте в списке 1 и на 4-м в списке 3 обгонит документ, попавший на 1-е место только один раз.

Decomposition

Пример: «подтянуть времена и неправильные глаголы» → два отдельных запроса, каждый находит своё.

Step-Back

Пример: общий вопрос про разницу времён находит и правило, и примеры — не только частный случай.

HyDE

Пример: «что такое passive voice» → сгенерированный абзац-объяснение → ищем документы, похожие на этот абзац.

Для проекта: из всех пяти реально пригодится Decomposition — несколько выявленных пробелов, несколько отдельных запросов. Остальное — про запас, на случай если простого dense-поиска не хватит.
